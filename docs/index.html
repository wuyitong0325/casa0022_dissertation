Discover hidden wildlife through sound.

Park Life Monitor helps visitors, educators and researchers understand wildlife activity in urban parks. A Raspberry Pi listens to environmental audio, detects birds and bats, and sends results to a Flutter Android app using MQTT. The web version is an interface preview.

What it is for

The project turns acoustic wildlife monitoring into an accessible public-facing experience.

Public engagement

Visitors can see immediate visual feedback when birds or bats are detected, making urban biodiversity easier to notice and discuss.

Environmental education

Species cards, sound examples, diary entries and charts help explain wildlife activity in a simple and engaging way.

Urban monitoring prototype

The system demonstrates how low-cost sensing, edge processing and mobile interaction can support biodiversity monitoring in green spaces.

How the system works

The exhibition version supports manual switching between bird and bat detection, so it is not limited by time-of-day rules.

1
Listen Raspberry Pi records environmental audio from the park or exhibition setup.
2
Analyse Bird and bat audio tools classify sound events locally on the device.
3
Publish Detection results are sent to the Flutter app through MQTT topics.
4
React The app shows animated bird or bat detection feedback.
5
Explore Visitors view diary entries, charts, atlas and species details.

Technology stack

The prototype combines embedded sensing, bioacoustic analysis and interactive app design.

Device and sensing

  • Raspberry Pi for audio capture and local control.
  • Python scripts for live bird, bat and exhibition modes.
  • Manual controller for Bird / Bat / Stop switching.

App and communication

  • Flutter and Dart for Android and web interface.
  • MQTT for live communication between device and app.
  • Web preview for browser-based interface viewing.

Audio and reference data

  • BirdNET/acoupi-related tools for bird sound analysis.
  • BatDetect2 for bat sound analysis.
  • xeno-canto, Biodiversity Ireland, GBIF, iNaturalist and Wikipedia are used where appropriate.

Setup notes

Notes for visitors and developers who want to try the app or inspect the source code.

Web preview and APK

The web version is provided as an interface preview in the browser. Because browsers cannot connect directly to a standard MQTT TCP port, live MQTT detections are intended for the Android app or a local Flutter run configuration. The public APK is for app preview. The exhibition phone uses a configured local build for live MQTT demonstration.

Developer configuration

Users who run the source code themselves should configure their own xeno-canto API key for online bird sound playback and their own MQTT broker credentials for live detection data.

flutter run -d chrome --dart-define=XENO_CANTO_API_KEY=your_key_here

Attribution

Key libraries, services and data sources used in the project.

This project was developed as part of an MSc dissertation with guidance from Duncan Wilson. The system uses Raspberry Pi, Flutter, Dart and MQTT. Bird sound analysis is based on BirdNET/acoupi-related tools, while bat detection uses BatDetect2. Wildlife reference sounds are sourced from xeno-canto for bird recordings and Biodiversity Ireland full-spectrum bat recordings where appropriate, with additional lookup support from GBIF, iNaturalist and xeno-canto where available. Species summaries and images are retrieved from Wikipedia species pages where appropriate.
