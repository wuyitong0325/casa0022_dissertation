Discover hidden wildlife through sound.

Park Life Monitor is an interactive bird and bat detection app for urban parks. A Raspberry Pi listens to environmental sounds, detects birds during the day and bats at night, and sends live results to a Flutter Android app using MQTT. The web version is provided as an interface preview for visitors.

What problem does it address?

Wildlife activity in cities is often present but invisible to the public. This project turns acoustic monitoring into a more understandable and engaging experience.

👥

For public engagement

Visitors can see immediate visual feedback when birds or bats are detected, making urban biodiversity easier to notice and discuss.

📡

For environmental sensing

The system demonstrates how low-cost edge devices can collect acoustic signals and send meaningful results to an interactive app.

📊

For education and explanation

Species cards, sound examples, diary entries and charts help translate technical monitoring data into a visitor-friendly format.

How it works

The exhibition version allows manual switching between bird and bat detection, so the demonstration is not limited by time-of-day rules.

1
Listen Raspberry Pi records environmental audio from the park or exhibition setup.
2
Analyse BirdNET/acoupi-related tools and BatDetect2 support bird and bat sound analysis.
3
Publish Detection results are sent to the app using MQTT topics.
4
React The app shows animated alerts, species information and discovery records.
5
Explore Visitors can view charts, sound examples, an atlas and discovery history.

Project features

The app is designed as an interactive public-facing experience, not only a technical dashboard.

✨

Interactive app experience

  • Live bird and bat detection alerts in the Android app.
  • Animated full-screen detection moments for exhibition impact.
  • Species cards with images, descriptions and sound examples.
  • Nature diary for recent discoveries.
🛠️

Exhibition control mode

  • Manual Bird / Bat / Stop buttons inside the app.
  • Commands are sent to the Raspberry Pi through MQTT.
  • The demo is not restricted by the 8pm automatic bat mode.
  • Designed for clear live demonstration during the degree show.

Technology stack

The project combines embedded sensing, acoustic AI tools and mobile app design.

🥧

Edge sensing

  • Raspberry Pi for audio capture and local control.
  • Python scripts for bird, bat and exhibition monitoring.
  • Manual exhibition controller for switching detection mode.
📱

App and communication

  • Flutter and Dart for Android and web interface.
  • MQTT for live communication between the Raspberry Pi and Android app.
  • Web preview for quick browser-based interface viewing.
🔊

Wildlife audio and data

  • BirdNET/acoupi-related tools for bird sound analysis.
  • BatDetect2 for bat sound analysis.
  • xeno-canto, Biodiversity Ireland, GBIF, iNaturalist and Wikipedia are used where appropriate.

Setup notes

These notes are for visitors or developers who want to try the app or inspect the source code.

🌐

Web preview and APK

The web version is provided as an interface preview in the browser. Because browsers cannot connect directly to a standard MQTT TCP port, live MQTT detections are intended for the Android app or a local Flutter run configuration. The public APK is for app preview. The exhibition device uses a configured local build for live MQTT demonstration.

🔑

Developer configuration

Users who run the source code themselves should configure their own xeno-canto API key for online bird sound playback and their own MQTT broker credentials for live detection data.

flutter run -d chrome --dart-define=XENO_CANTO_API_KEY=your_key_here

Attribution

Key libraries, services and data sources used in the project.

This project was developed as part of an MSc dissertation with guidance from Duncan Wilson. The system uses Raspberry Pi, Flutter, Dart and MQTT for sensing, communication and app development. Bird sound analysis is based on BirdNET/acoupi-related tools, while bat detection uses BatDetect2. Wildlife reference sounds are sourced from xeno-canto for bird recordings and Biodiversity Ireland full-spectrum bat recordings where appropriate, with additional lookup support from GBIF, iNaturalist and xeno-canto where available. Species summaries and images are retrieved from Wikipedia species pages where appropriate.
