Park Life Monitor

Park Life Monitor is an interactive bird and bat detection app for urban parks. A Raspberry Pi listens to environmental sounds, detects birds during the day and bats at night, and sends live results to a Flutter Android app using MQTT. The web version is provided as an interface preview for visitors.

What it does

  • Shows live animated bird and bat detection alerts in the Android app.
  • Displays species information, images, and sound examples.
  • Records discoveries in a diary-style interface.
  • Summarises activity using simple charts and insights.
  • Supports public engagement with urban biodiversity.

Who it is for

The project is designed for park visitors, environmental educators, researchers, and exhibition audiences who want to understand wildlife activity that is often difficult to notice directly.

Technical stack

  • Raspberry Pi for edge sensing and audio capture.
  • Flutter and Dart for the mobile/web app.
  • MQTT for live communication between the Raspberry Pi and Android app.
  • BirdNET/acoupi-related tools for bird sound analysis.
  • BatDetect2 for bat sound analysis.
  • xeno-canto, Biodiversity Ireland, GBIF, iNaturalist, and Wikipedia are used for reference data where appropriate.

Setup notes

The web version is provided as an interface preview in the browser. Because browsers cannot connect directly to a standard MQTT TCP port, live MQTT detections are intended for the Android APK or a local Flutter run configuration. Users who run the source code themselves should configure their own xeno-canto API key for online bird sound playback and their own MQTT broker credentials for live detection data.

flutter run -d chrome --dart-define=XENO_CANTO_API_KEY=your_key_here

Demo MQTT credentials may be provided during the exhibition. They should not be used for sensitive or long-term data.

Attribution

This project was developed as part of an MSc dissertation with guidance from Duncan Wilson. Bird reference sounds are sourced from xeno-canto where available. Bat reference sounds use sources such as Biodiversity Ireland full-spectrum bat recordings, with additional lookup support from GBIF, iNaturalist and xeno-canto where available. Species summaries and images are retrieved from Wikipedia species pages where appropriate.
